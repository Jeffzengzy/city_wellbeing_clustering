# City Wellbeing Clustering

This project is adapted from selected parts of STAT 437 Assignment 7.
I reorganized the work into a short report about city living conditions.
The analysis compares hierarchical clustering methods and uses three groups.

- `City_Wellbeing_Analysis.ipynb`: full analysis, supporting checks, and saved outputs.
- `Adapted report .docx`: the short report.
- `original_homework/`: the unchanged original homework notebook and submitted PDF.
- `movehub_data_cleaned2.csv`: the cleaned dataset copied directly from Homework 7.

The course materials trace the data to MoveHub.
Full dataset: https://www.kaggle.com/datasets/blitzr/movehub-city-rankings
The supplied CSV is included; no download is needed to run this analysis.
Open the notebook from this folder and choose **Restart Kernel and Run All Cells**.
Required packages and an installation command are listed at the top of the notebook.
